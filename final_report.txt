**核心功能与工作流程：**

1. **自然语言驱动的视频制作**：用户只需输入类似 '制作一个 60 秒的动画解释视频，讲解神经网络如何学习' 这样的提示词，系统就会自动启动完整的生产管线。

2. **双渲染引擎架构**：
   - **Remotion**：基于 React 的渲染引擎，适合数据驱动的解释器、教育内容，支持弹簧动画、文字卡片、统计卡片、图表、TikTok 风格逐字字幕等
   - **HyperFrames**：基于 HTML/CSS/GSAP 的渲染引擎，适合动态图形、产品宣传、网站转视频、SVG 角色动画等

3. **真实素材视频制作**：这是 OpenMontage 的重要创新点。系统可以从 Archive.org、NASA、Wikimedia Commons、Pexels 等免费素材库构建 CLIP 可搜索的素材库，检索真实运动镜头，剪辑成时间线，渲染成片。这不是常见的 '动画几张静态图然后称之为视频' 的伎俩。

4. **零成本制作路径**：即使没有任何付费 API Key，用户也可以制作视频：
   - Piper TTS 提供免费的离线文本转语音
   - Archive.org + NASA + Wikimedia Commons 提供免费素材
   - Pexels + Unsplash + Pixabay 提供免费素材（开发者 Key 免费获取）
   - Remotion 提供 React 基础渲染
   - FFmpeg 提供编码、字幕烧录、音频混合、调色

5. **11 种专业视频管线**：
   - Animated Explainer：AI 生成的解释视频
   - Animation：动态图形、动画序列
   - Avatar Spokesperson：虚拟人讲解视频
   - Cinematic：电影级预告片、情绪驱动剪辑
   - Clip Factory：长视频批量剪辑
   - Documentary Montage：纪录片蒙太奇（真实素材）
   - Hybrid：实拍素材 + AI 生成辅助视觉
   - Localization & Dub：字幕、配音、翻译
   - Podcast Repurpose：播客转视频
   - Screen Demo：软件录屏演示
   - Talking Head：主讲人视频

   - 执行前预估成本
   - 预留预算锁定资金
   - 执行后对账记录实际花费
   - 可配置模式：observe（仅跟踪）、warn（超支警告）、cap（硬限制）

   - 总预算上限（默认 $10）

8. **多平台 AI 助手兼容**：支持 Claude Code、Cursor、GitHub Copilot、Codex、Windsurf 等主流 AI 编程助手，每个平台都有专门的配置文件。

在 AI 能力方面，项目最大的亮点是「多模型兼容」——几乎支持市面上所有主流 AI 服务商，包括 Anspire、AIHubMix、Gemini、OpenAI 兼容接口（可接 DeepSeek、通义千问等）、Claude、Ollama 本地模型等。这种设计让用户可以根据成本、性能、网络环境灵活选择，甚至支持多模型路由和降级策略。

数据源方面，项目展现了极强的「数据聚合」能力。行情数据层面集成了 TickFlow、AkShare、Tushare、Pytdx、Baostock、YFinance、Longbridge 共 7 个数据源，新闻搜索层面集成了 Anspire AI Search、SerpAPI、Tavily、Bocha、Brave、MiniMax、SearXNG 共 7 个搜索服务，还可选接入 Stock Sentiment API 获取 Reddit/X/Polymarket 的社交舆情数据。这种多源设计不仅提高了数据可靠性，还能根据不同市场的特点进行智能降级——比如日股和韩股的部分高阶功能（资金流、龙虎榜等）会自动标记为不支持，避免返回错误数据。

功能层面，项目提供了完整的分析闭环：从自选股管理（支持图片、CSV/Excel、剪贴板导入，以及代码/名称/拼音/别名智能补全）→ 自动化分析（每日定时或手动触发）→ AI 决策报告生成（核心结论、评分、趋势、买卖点位、风险警报、催化因素、操作检查清单）→ 多渠道推送。Web 工作台还提供了任务进度监控、历史报告查看、完整 Markdown 报告、回测、持仓管理、浅色/深色主题等丰富的交互功能。

Agent 策略问股是另一个亮点功能，内置了 15 种投资策略（均线金叉、缠论、波浪理论、多头趋势、热点题材、事件驱动、成长质量、预期重估等），用户可以通过 Web 聊天界面进行多轮追问，系统会调用实时行情、K 线、技术指标、新闻和风险信息来回答问题。这相当于一个「AI 投顾助手」，大大降低了普通投资者使用专业策略的门槛。

部署方式上，项目提供了最友好的「零门槛」方案——GitHub Actions 部署，用户只需 Fork 仓库、配置 Secrets（AI Key + 通知渠道 + 自选股列表），5 分钟即可完成部署，每个工作日 18:00 自动执行分析。同时也支持本地运行、Docker 部署、云服务器部署等多种方式，满足不同用户的需求。

项目还规划了生态扩展，同系列的 AlphaSift（多因子选股与全市场扫描）和 AlphaEvo（策略回测与自我进化）项目未来可能与 DSA 实现候选股导入、回测验证和报告联动，形成从选股 → 分析 → 策略验证的完整投资工具链。
