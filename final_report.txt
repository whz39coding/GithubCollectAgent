   项目简介: Headroom 是一个专为 AI Agent 设计的上下文压缩层，能在不损失准确性的前提下将输入 token 减少 60–95%。它通过本地运行的库、代理、MCP 服务器等多种方式，智能压缩工具输出、日志、RAG 块、文件和对话历史，同时支持可逆压缩（CCR）和跨 Agent 记忆共享，堪称 AI 开发者的'省钱神器'。
   亮点: 多算法智能压缩：针对 JSON、代码（AST）、文本（Kompress-base 模型）等不同内容类型自动选择最优压缩策略; 可逆压缩（CCR）：原始数据本地缓存，LLM 可按需检索，兼顾压缩率与信息完整性; 输出 Token 优化：不仅压缩输入，还通过 Verbosity Steering 和 Effort Routing 减少模型回复中的废话，实测节省约 31.7% 输出 Token; 跨 Agent 记忆共享：支持 Claude Code、Codex、Cursor 等多 Agent 共享上下文，自动去重; 零代码集成：提供 Proxy 模式，一行命令即可接入现有工作流，无需修改任何代码
   详细报告: Headroom 解决的核心痛点是：随着 AI Agent 处理的任务越来越复杂，上下文窗口迅速被填满，导致成本飙升、响应变慢甚至任务失败。传统方案要么只压缩文本，要么依赖云服务，而 Headroom 提供了一个本地优先、全栈覆盖的解决方案。

其技术架构分为三层：ContentRouter 检测内容类型并路由到专用压缩器；SmartCrusher 处理 JSON 结构，CodeCompressor 基于 AST 压缩代码，Kompress-base 是专为 Agent 文本训练的 HuggingFace 模型；CacheAligner 稳定前缀以命中 KV 缓存；CCR（Context Compression with Retrieval）确保原始数据可逆。

项目支持多种集成方式：作为 Python/TypeScript 库直接调用 `compress()`；通过 `headroom proxy` 启动透明代理；用 `headroom wrap` 一键包装 Claude Code、Cursor 等主流编码 Agent；或作为 MCP Server 提供 `headroom_compress`、`headroom_retrieve` 等工具。

实测数据亮眼：代码搜索任务从 17,765 tokens 压缩至 1,408（节省 92%），SRE 故障排查从 65,694 降至 5,118（节省 92%），且在 GSM8K、TruthfulQA 等基准测试中准确性几乎无损。

此外，`headroom learn` 功能会分析失败会话，自动将修正写入 CLAUDE.md 等配置文件，实现持续优化。对于企业级用户，还支持 GitHub Copilot CLI 订阅模式、SSL 检查环境配置、Docker 部署等高级特性。
