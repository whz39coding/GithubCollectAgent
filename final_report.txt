**核心功能与技术原理：**
项目基于 Playwright 浏览器自动化框架，其核心逻辑是“以逸待劳”。传统的爬虫需要逆向分析复杂的加密算法（如 X-S 签名等），而 MediaCrawler 巧妙地保留了浏览器的登录态，直接在浏览器上下文中通过 JS 表达式获取签名参数，从而免去了繁琐的 JS 逆向过程。

**支持的平台与数据类型：**
它覆盖了主流自媒体平台（小红书、抖音、快手、B站、微博、贴吧、知乎），功能矩阵非常全面。支持关键词搜索、指定帖子 ID 爬取、二级评论获取、指定创作者主页抓取。此外，还支持登录态缓存（避免频繁扫码）、IP 代理池（防封禁）以及生成评论词云图（数据可视化）。

**运行与使用体验：**
项目推荐使用 uv（极速 Python 包管理器）进行环境管理，支持 Node.js 环境。它提供了多种启动方式：CLI 命令行（适合极客）、WebUI 可视化界面（通过 Uvicorn 启动 API 服务，适合非技术人员）以及作为 Python 模块调用。数据保存格式也非常灵活，支持 CSV、JSON、JSONL、Excel、SQLite 和 MySQL，方便接入各种下游数据分析流程。
